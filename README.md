## От заготовки до готовой проволоки

Dragging помогает рассчитывать маршрут волочения и проверять его параметры без подключения к интернету. Интерфейс **Precision Glass** поддерживает светлую и тёмную темы, крупные поля ввода и ручную правку проходов.

| Режим | Возможности |
|---|---|
| **Маршрут** | Ввод диаметров заготовки и до 15 блоков, автоматический расчёт обжатия между соседними диаметрами. |
| **Линейный маршрут** | Расчёт последовательности диаметров по исходному и конечному диаметрам, числу проходов и углероду; суммарное и единичное обжатие, ВСР, ручная корректировка. |
| **Цинковое покрытие** | Расчёт количества цинка на заготовке для групп С, Ж и ОЖ. |
| **Справка** | Формулы и таблица плотности цинка в двух вкладках. |

Десятичную часть можно вводить через точку или запятую. Переключатели темы и прозрачности доступны в верхней панели. Размытие по умолчанию выключено; режим без прозрачности сохраняет все функции.

## Установка

1. Скачайте `Dragging-3.1.0+12.apk` из [релиза 3.1.0](https://github.com/Abynarc/Dragging/releases/tag/v3.1.0).
2. Откройте файл на Android. Если система запросит разрешение на установку из выбранного источника, предоставьте его.
3. Установите приложение и откройте **«Маршрут волочения»**.

Версия приложения — **3.1.0**, номер сборки — **12**. Минимальная заявленная версия Android — 5.0/API 21; фактическая проверка выполнена на эмуляторе Android 15/API 35. APK подписана прежним локальным debug-сертификатом. Обновление поверх сохранённой 3.0.0+11 с тем же сертификатом проверено; совместимость с APK, подписанной другим ключом, не заявляется.

Для установки через ADB:

```sh
adb devices
adb -s SERIAL install -r Dragging-3.1.0+12.apk
```

Замените `SERIAL` идентификатором нужного устройства. Контрольная сумма APK находится в `SHA256SUMS.txt` в релизе. Введённые расчёты не сохраняются после завершения процесса: при необходимости запишите результаты заранее.

## Попробуйте на примере

В линейном маршруте введите **D Заг. = 5,5**, **D Чист. = 2**, **число проходов = 8**. Полностью замените содержимое поля «Углерод» значением **0,7** и нажмите «Рассчитать».

| Показатель | Результат |
|---|---:|
| Суммарное обжатие | **86,78%** |
| Единичное обжатие | **22,35%** |
| ВСР заготовки | **112,50–122,50** |
| ВСР готовой проволоки | **203,95–213,95** |

Диаметры: `5.50 → 4.85 → 4.27 → 3.76 → 3.32 → 2.92 → 2.58 → 2.27 → 2.00`.

Ручная правка диаметра обновляет соседние обжатия. Сводные показатели пересчитываются при новом основном расчёте. Значения в интерфейсе выводятся с десятичной точкой; округление и расчётная методика сохранены из предыдущей версии.

## Сборка из исходников

Проверенное окружение: **Flutter 3.29.2 / Dart 3.7.2**, **JDK 17**, Android SDK Platform **35**, Build Tools **35.0.1**, NDK **27.0.12077973**. Gradle Wrapper задаёт версию **8.10.2**.

Установите Flutter и Android SDK, настройте `JAVA_HOME` на JDK 17 и примите необходимые лицензии Android SDK.

```sh
git clone https://github.com/Abynarc/Dragging.git
cd Dragging/wire_drawing_calc
flutter pub get
flutter build apk --release --no-pub
```

APK появится в `wire_drawing_calc/build/app/outputs/flutter-apk/app-release.apk` относительно корня репозитория. На машине с заполненным кэшем зависимостей можно использовать `flutter pub get --offline`. Production-точка входа — `lib/main.dart`.

В текущей конфигурации release-сборка использует локальный debug-ключ. На другой машине сертификат обычно будет другим, поэтому такая APK не сможет обновить установленное приложение с исходной подписью. Закрытые ключи в репозиторий не входят. Подпись для магазина настраивается отдельно.

<details>
<summary>Сохранённые особенности исходной методики</summary>

Редизайн не меняет формулы, коэффициенты и округление. Справка и вычисления исторически расходятся в отдельных местах: ВСР использует в коде `0.01 × U`, а в справке указано `0.01 × S`; для цинка Ж при 0,65–0,75 мм код использует 60, таблица показывает 50; код принимает диаметры от 0,18 мм; для ОЖ код использует K=1,2, справка указывает 1,2–1,3. Эти особенности сохранены для совместимости и защищены эталонными тестами.
